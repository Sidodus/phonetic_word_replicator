# Internationalization (i18n)

> Status: current for v2.0.0. UI localization: **11 locales**. Game dictionaries: the
> original **8 languages** — these are separate concepts; see "UI vs game languages".

## UI vs game languages

| | Game languages (dictionaries) | UI locales (interface strings) |
|---|---|---|
| Set | en, fr, de, es, it, nl, hi, zh | en, fr, de, es, it, nl, hi, zh, **yo, ig, ha** |
| Source | `public/dictionaries/` (Wiktionary) | `messages/*.json` |
| Switching | Home screen picker | Settings → Interface language (default: browser) |

Yorùbá, Igbo and Hausa localize the interface only. They honour the owner's number-to-words
locale lineage (en/fr/ha/yo/ig/es) where Nigerian-language support is a flagship; no
Wiktionary pronunciation packs exist for them, so they have no game dictionary.

## Runtime

Custom typed i18n (`src/lib/i18n/`) — rationale in ADR-0004:

- `messages/en.json` is **canonical**; CI tests enforce exact key-structure parity for every
  locale (recursive key walk in `tests/unit/i18n.test.ts`).
- Fallback chain: requested locale → English → the key itself (never an empty label).
- Interpolation: `{name}` placeholders only; **plural suffixes** use `{s}`-style tokens fed
  per-locale by `pluralVars(locale, count)`:
  | Locales | Token semantics |
  |---|---|
  | en, fr, es | `{s}` = `"s"` or `""` (attempt → attempts) |
  | it | `{s}` = final vowel `"o"`/`"i"` (tentativo → tentativi) |
  | de | `{e}` = `"e"` or `""` (Versuch → Versuche) |
  | nl | `{en}` = `"en"` or `""` (poging → pogingen) |
  | hi, zh, yo, ig, ha | no suffix token; phrased naturally for any count |
- Messages are lazy-loaded per locale (webpack splits one small chunk each).
- Locale preference lives in the profile store (`settings.uiLocale`, `"auto"` = browser).

## Protected values (parity-tested)

- `app.phonetic` = `/fəˈnɛtɪk wɜːd ɹɛplɪkeɪtə/` in every locale.
- `standard.ipa` / `standard.xsampa` labels ("IPA" / "X-SAMPA"; es uses "AFI" for the full
  name only).
- `settings.ipaDesc` keeps `/ˈdɪkʃ(ə)n(ə)ɹɪ/`; `settings.xsampaDesc` keeps `/"dIkS(@)n(@)r\I/`
  (JSON-escaped `\"` and `\\`).
- Proper nouns never translated: Saheed Odulaja, Wiktionary, wikt2pron, Next.js, TypeScript,
  React-Bootstrap, GitHub, MIT.

## Adding a UI locale

1. Copy `messages/en.json`, translate every value (keep keys, order, placeholders).
2. Add the code to `UI_LOCALE_CODES` (`src/lib/i18n/locales.ts`) and `UI_LOCALES` +
   `UI_LOCALE_META` + the loader entry (`src/lib/i18n/index.ts`).
3. Extend `pluralVars` if the language inflects plurals.
4. `npm test` — the parity suite rejects missing/extra keys, empty values, and broken
   placeholders.
5. Update the matrix above.

Translation conventions: natural app tone (fix, don't inherit, the v1 machine-translation
artifacts); keep badge names short; games/phonetics terminology may borrow English loanwords
where the target language has no established term (as v1 did).
